# infinite flow

A Flow Free style puzzle game. Every level is procedurally generated and verified by a solver to have exactly one solution, which always fills the whole board.

**Play it: https://tobyrichmond12-max.github.io/infinite-flow/**

Six packs (5x5 through 10x10, 30 levels each) plus an endless mode. Stars for minimum-move clears, synthesized water sounds, works offline-ish as a home screen app.

Built with Claude.
